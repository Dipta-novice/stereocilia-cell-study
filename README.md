An end-to-end, CPU-optimized image analysis pipeline designed to bridge the gap between raw microscopic imaging and quantitative biological insights. The framework features a modular segmentation benchmarking suite (testing Watershed, Multi-Otsu, and Cellpose), multi-scale feature extraction for stereocilia morphology and texture, and a row-based clustering classifier to automatically categorize hair cells into functional cochlear regions. Powered by a Streamlit-based interface, VASCilia enables rapid, reproducible tonotopic mapping and structural validation for auditory research.
